# HarmonyAgent 学习仪表盘设计规格（草案，待评审）

**状态：** 已获用户批准（2026-08-17；待拍板 3 项全部按草案建议定稿：今日页卡片入口、30 天横条热力、server 增补 activeDayKeys）  
**日期：** 2026-08-17  
**适用范围：** HarmonyAgent 第二轮能力（Sprint E）  
**前置：** 长期学习者模型规格（2026-08-17，已批准并实现）

## 1. 设计结论

新增一个**纯展示**的「学习数据」页，把学习者模型派生出的坚持、掌握、节律三类画像完整呈现，作为「自迭代学习伙伴」的可视化证明。零新 API（复用 `GET /api/learner/profile` 与书列表）、零 LLM、零写入；mock 演示书不参与（仅真实数据）。入口为今日页的「学习数据」卡片，不新增底部 Tab。

## 2. 问题与目标

学习者模型（Sprint B）已在后台驱动今日页推荐，但用户（和比赛评委）看不到这层智能。DeepTutor 的 Learning Space 证明学习画像本身就是一个大面。本规格给它一个轻量、诚实、只读的展示面。

## 3. 范围

### 3.1 包含

- **坚持区**：连续学习天数（streak）、近 30 天活跃热力横条（30 格，有/无事件两级 + 今日高亮）、今日是否已学。
- **掌握区**：概念总数及分布（已掌握/学习中/待复习/暂无记录各多少），Top 5 薄弱概念（掌握度升序）与悬崖概念专区（含「去复习」直达）。
- **节律区**：四桶时段分布条形图（上午/下午/晚上/深夜）+ 日均学习事件数。
- 数据为空（无真实书或无事件）时展示空态引导（去上传/去学习），不展示 mock 数据。

### 3.2 明确排除

- 任何写入、设置、目标管理；
- 周报/月报、历史趋势曲线（首版只有当前画像）；
- 导出/分享；
- mock 演示书数据。

## 4. 信息架构与交互

- 入口：今日页次行动区新增「学习数据」卡片（显示 streak 摘要），点击全屏页；返回回今日。
- 页面路由：`#learning-data`，刷新可恢复（与既有 hash 路由一致）。
- 悬崖概念「去复习」：跳转到来源书（`openRealBook`），与今日页悬崖候选同链路。

## 5. 数据来源

| 内容 | 来源 |
| --- | --- |
| streak / activeDays30 / studiedToday / 时段分布 / 日均事件 | `GET /api/learner/profile` 的 `rhythm` |
| 概念分布与薄弱/悬崖列表 | 同接口 `concepts`（mastery 阈值：≥0.8 已掌握，0.3–0.8 学习中，<0.3 待复习，无作答 暂无记录；悬崖即 `forgettingCliff`） |
| 热力条 | 首版由 `rhythm` 推不出逐日序列 → **server 在 rhythm 增补 `activeDayKeys: string[]`（近 30 天活跃日 YYYY-MM-DD）**，纯派生补充，非新 API |

## 6. 验收标准

1. 有 streak=3 的数据时，坚持区显示 3 天，热力条对应 3 格点亮；
2. 悬崖概念出现在专区，点击「去复习」进入来源书；
3. 无真实书时整页空态引导，无 mock 数据泄漏；
4. `#learning-data` 刷新后页面仍在；
5. 全程无 LLM 调用；server/admin 测试全绿。
