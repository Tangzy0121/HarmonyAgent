# P0-06 Agent 抽屉与物理交互结果

**日期：** 2026-07-22
**状态：** 已完成

## 交付

- Agent 保持独立圆形入口，不占用第四个一级导航位置。
- 抽屉只有关闭、75% 高度与全屏三种状态；按钮为手势提供等价的非手势入口。
- 抓取区采用 8px 拖动意图阈值：未超过阈值不会进入拖动。
- 上下边界施加渐进阻力；松手后依据位移和纵向速度回到 75%、全屏或关闭。
- 默认状态下快速下甩关闭；全屏下慢速下拖先回到 75%，明显或快速下甩关闭。
- 保留可移除的页面上下文、建议问题与固定输入区；关闭不会卸载三项目的地页面，地图视口和页面局部状态继续由应用壳保存。

## 可访问性与降级

- 全屏／75% 切换和关闭均保留可点击按钮及清晰标签。
- 抓取区只处理自身的垂直拖动，不与页面主内容手势竞争。
- 减少动态效果时，全局过渡时间会降至最小值；虚拟键盘通过动态视口配置重新计算内容高度。
