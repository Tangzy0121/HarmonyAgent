# 中性侧光系统试点计划

**日期：** 2026-07-24

**状态：** 已完成，待用户视觉确认

**试点页面：** 知识库

## 1. 当前方向

知识库恢复原有浅灰背景、近白内容面和近黑交互色，不再使用森林绿环境色。继续保留材质实验中已经确认有效的清透玻璃、固定主光方向、边缘高光、接触阴影和远距离环境阴影。

原有白色侧光对比度偏低，本轮通过提高左上白光亮度、压深右侧冷灰填充和中性环境阴影，使光照方向在不引入彩色光的前提下更明确。

## 2. 实施范围

- 知识库页面中性背景光场；
- 本周重点资料内容面；
- 搜索、筛选和底部导航玻璃；
- 资料列表稳定实体面；
- 近黑筛选选中态、资料封面和 Agent 按钮；
- 材质实验页默认状态恢复为中性侧光。

不修改页面信息结构、数据、交互流程和后续阅读页面。

## 3. 验收标准

1. 页面恢复原有黑白视觉张力。
2. 左上白色侧光能够被清楚感知，但不形成高光污渍。
3. 玻璃控制与内容实体面保持明确空间距离。
4. 深色按钮只占小面积，不形成大块黑色填充。
5. 390 × 844 与 360 × 780 无横向溢出。
6. 搜索、筛选、资料入口、主导航和 Agent 交互保持可用。
7. TypeScript 与 Vite 生产构建通过。
