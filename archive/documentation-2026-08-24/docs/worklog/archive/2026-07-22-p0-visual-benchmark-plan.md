## 1. 目标

在引入首次使用旅程或真实能力之前，先制作四个视觉与交互基准状态，验证产品结构：

1. 今日；
2. 学习地图；
3. 知识库；
4. 默认吸附在 75% 高度的 Agent 抽屉。

本阶段重点验证编辑式极简、建筑式磨砂玻璃、空间层级、地图惯性与弱吸附，以及抽屉的阻力和吸附行为。

## 2. 约束

- 不接入 `server/`、LLM、真实上传、向量数据库或图谱算法。
- 本阶段不修改 `entry/`。
- 一级导航仅保留**今日／学习／知识库**；Agent 是独立圆形入口。
- 统一使用《机器学习》第三章模拟数据。
- 不扩展 S01—S10 的注册、上传、文件理解或深入学习流程。
- 不新增未经确认的产品能力，也不将原型做成管理后台。

## 4. 建议实施顺序

`P0-01 → P0-02 → P0-06（基础骨架）→ P0-03 → P0-04 → P0-05 → P0-06（物理交互打磨）→ P0-07`

先实现 Agent 基础骨架，使各页面能在真实的底部占位和浮层上下文中被检查；待页面具备真实背景后，再集中打磨抽屉物理交互。

## 5. 完成标准

只有当四个基准状态均能从 `admin/` 运行、共享一致的模拟数据，并展示规定的导航、视觉材质层级、地图运动、抽屉吸附与状态恢复行为时，P0 才算完成。`results/` 中还必须有带日期的验收记录，以及视觉与构建证据。
