# 团队分歧点四象限（紧急 × 重要）

> **状态：历史会议议程，已不作为当前任务来源。** 其中“端 A2A 为主入口”“卡片交互”“单次行为写回掌握度”等讨论已被 [PRD](../PRD.md) 的独立 App、单点深入学习和可解释学习证据原则替代。保留本文仅用于追溯当时的分歧与讨论背景。

> 用法：第一象限 = 下次开会先谈，谈不完不散会；第二象限 = 定个 deadline，分头准备后对齐；第三象限 = 会上快速过，5分钟内拍板；第四象限 = 能砍就砍，别花时间。

---

## 象限一：重要且紧急（下次会议的主菜，逐项拍板）

| # | 议题 | 要产出什么 | 为什么急 |
|---|---|---|---|
| 1 | **演示主角与剧本** | 一页纸演示动线：选定一个具体用户（如"大二学ML的学生"）、一门具体课程语料，逐帧标注每个镜头展示的端A2A能力点 | 所有功能取舍的上游，剧本不定，P0范围定不下来 |
| 2 | **AgentCard skills 边界** | 合并后的触发句式清单（各写10条 → 去重 → 归类到4个skills） | 决定小艺什么时候把请求给我们，写晚了联调没法测 |
| 3 | **学习者模型可解释口径** | 掌握度计算规则 + 哪些行为算证据（答题/自评/停留时长各占多少） | 一旦定了，表结构、规则引擎、可视化全跟着走，返工成本最高 |
| 4 | **保底触发条件** | 明确"端A2A联调卡到什么程度、最晚哪天退到平台单Agent+云知识库保底" | 协议V0.6较新有踩坑概率，先约定好过到时候纠结 |

## 散会前的检查清单

会议结束时，白纸黑字应留下四样东西：

- [ ] 演示剧本一页纸（含逐帧能力点标注）
- [ ] skills 触发句式清单（4个skills，每个≥5条句式）
- [ ] 掌握度计算口径（公式 + 行为证据权重）
- [ ] 保底触发条件（退化方案 + 决策死线）

> 缺任何一样 = 会没开完。
