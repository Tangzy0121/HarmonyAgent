# HarmonyAgent 当前实施任务清单

> 当前产品基线以 [PRD](../PRD.md) 为准。本文只管理实施顺序；完成后将 `[ ]` 改为 `[x]`。小艺与端 A2A 是可选连接器，不是核心流程前置条件。

## P0：代码即高保真原型

目标：以固定的《机器学习第三章》模拟数据完成四张可运行基准页，验证独立 App 的结构、视觉和交互。

- [ ] 建立设计 token、全局壳层、安全区和“今日｜学习｜知识库 + Agent”导航；
- [ ] 建立统一模拟数据：机器学习基础空间、1 份资料、4 个主题、12 个节点、关系、引用、Agent 会话、深入学习任务与今日任务；
- [ ] 实现今日：新用户空白、一个主要行动、成果与安静结束状态；
- [ ] 实现学习地图：平移、缩放、节点聚焦、学习状态图层与地图状态恢复；
- [ ] 实现知识库：空间范围、列表、基础筛选、文件状态与理解结果入口；
- [ ] 实现独立 Agent 抽屉：弱上下文、75%/全屏/关闭、引用、建议问题与会话状态；
- [ ] 实现节点抽屉：概要、路径、邻近节点、资料跳转与深入学习入口；
- [ ] 实现全局状态：空白、加载、部分完成、错误、离线、权限不足和可恢复中断；
- [ ] 对移动端真机验证导航、中文排版、键盘避让、抽屉手势、地图手势和减少动态模式。

## P1：首次使用闭环

目标：使用同一套模拟数据完整演示 S01—S10；不依赖小艺、真实模型或后端。

- [ ] S01 欢迎、模拟注册、协议展开、失败与重试；
- [ ] S02 轻量个性化：身份、主题、目标、Agent 偏向，均可跳过；
- [ ] S03 今日空白：上传第一份资料与示例知识空间入口；
- [ ] S04 上传与解析：待上传、上传中、解析中、部分完成、失败重试、后台继续与完成；
- [ ] S05 归属确认：建议依据、确认、更换与新建知识空间；
- [ ] S06 文件理解结果：概述、主题、节点、前置、出处、三条下一步路径；
- [ ] S07 可选自由 Agent：从文件进入、查看引用、确认转入深入学习或返回；
- [ ] S08 单知识点深入学习：目标、解释、回忆/应用、验证、反馈、自动保存和完成摘要；
- [ ] S09 地图变化：聚焦本次新增知识斑块，节点与来源可互相跳转；
- [ ] S10 今日收尾：安排到明天、调整/撤销、今天继续与暂不安排；
- [ ] 以首次用户旅程进行至少两次连贯演示，记录理解与交互问题。

## P2：真实能力与连接器

P1 的结构和开放决策确认后，再按可替换接口逐步接入：

- [ ] 文件上传、解析、渐进结果和原文定位；
- [ ] 知识点、关系、引用和可修正的理解结果；
- [ ] RAG、真实 Agent 会话、停止/重试与会话历史；
- [ ] 学习证据、可解释状态、复习任务与通知；
- [ ] 本地保存、云端处理、同步、授权撤回与数据删除；
- [ ] 小艺、端 A2A、系统分享、通知和桌面组件等可选连接器。

## 代码审查与重构

- [ ] 产出《仓库差距与重构清单》，将旧代码标记为保留、迁移、重构、废弃或暂缓；
- [ ] 将 A2A、AgentExtensionAbility 和系统接口封装为连接层，不直接驱动页面主流程；
- [ ] 移除或隔离 Agent 第四个 Tab、卡片流主链路、文件节点图谱与“单次交互即掌握”等旧假设；
- [ ] 为 P2 明确数据对象、接口契约、隐私边界与错误恢复策略。
