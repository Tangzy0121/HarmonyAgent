# 历史方案说明

`plans/` 和 `specs/` 保存原型开发过程中形成的设计与实施记录，主要用于追溯当时的目标、假设和技术选择。

这些文件中的“完成”“验收”“MVP”“真实能力”等表述只对应其创建时的局部任务，不能作为当前产品状态证明，也不代表相关 API、数据模型或信息架构已经冻结。

阅读顺序：

1. 当前原型范围、实现状态与验收以 [`../MVP_SCOPE.md`](../MVP_SCOPE.md) 为准；
2. 长期产品方向参考 [`../PRD.md`](../PRD.md)，但其中 v0.2 信息架构仍待重构；
3. 本目录文件只在需要理解历史决策或复用具体实现思路时查阅。

如果历史文档与当前范围冲突，优先采用 `MVP_SCOPE.md` 和用户最新确认并记录的决策。
