# ADR-001：文档真源与烟晶材质基线

> 状态：已接受
> 日期：2026-08-03
> 决策范围：产品文档优先级、当前视觉基线、跨端材质实现边界

## 背景

仓库在白绿实体化探索、旧版恢复和跨平台迁移讨论后，同时存在两套互相冲突的描述：一套要求全面不透明并禁止模糊与折射，另一套以可运行的灰紫连续知识场和烟晶悬浮控制为当前体验基准。单一线性文档优先级还会让 PRD、设计规范和技术方案越权覆盖彼此的专项决策。

## 决策

### 1. 文档按关注点设立真源

| 关注点 | 当前真源 |
| --- | --- |
| 产品定位、范围、功能与验收 | `docs/PRD.md` |
| 产品身份与高层设计原则 | `PRODUCT.md`、`DESIGN.md` |
| 视觉语言与材质边界 | `docs/design-system/视觉设计规范.md` |
| 组件行为、手势、响应式与无障碍 | `docs/design-system/UI与交互规范.md` |
| 用户旅程与页面关系 | `docs/design-system/用户旅程.md`、`docs/design-system/信息架构与页面结构.md` |
| 客户端架构与迁移边界 | `docs/architecture/` 下已接受的 ADR 与迁移方案 |
| 当前具体视觉与交互参考 | 可运行的 `admin/` 及其基准截图 |

同一关注点发生冲突时，按以下顺序处理：

1. 用户最新确认并写入已接受 ADR 的决策；
2. 当前专项规范；
3. 当前可运行实现与验收截图；
4. README、worklog、归档方案、旧代码注释与历史实现。

`docs/api/` 只提供技术参考，不定义产品或设计方向。历史记录保持原文，不因后续决策而回写，但不得作为新功能需求来源。

### 2. 保留烟晶材质

当前正式视觉继续使用浅灰紫连续知识场、深色编辑排版、稳定实体内容和烟晶悬浮控制：

- 正文、资料、普通列表、消息、证据和深层学习内容保持实体或开放排版；
- 页眉用户区、底部导航、短时筛选、Agent 入口、Agent 抽屉和必要覆盖层可以使用烟晶；
- 桃色继续用于品牌、Agent 和即时行动，不扩散为页面主题；
- 不新增与空间职责无关的玻璃卡片、霓虹辉光或装饰性连续动画。

### 3. 共享体验，不共享 Web 材质实现

`admin/` 是视觉与交互基准，不是移动端生产代码。HarmonyOS、Android 与 iOS 共享烟晶组件的语义职责、构图、状态、Token、截图和运动验收，不共享 CSS、`backdrop-filter`、SVG 位移贴图、Pointer Events 或祖先选择器。

每个平台使用自身原生能力实现烟晶，并必须具备：

- 目标真机性能记录；
- 减少动态模式；
- 关闭实时模糊后的半透明着色或实体降级态；
- 降级后仍完整的文字对比、信息层级和交互状态。

## 影响

- `admin/` 在完成基准截图后冻结，只接受阻塞性修复；
- ArkUI 首个切片必须同时验收烟晶正常态与实体降级态；
- 迁移工作不得逐行翻译 `LociGlass` 或全局 CSS；
- 新增烟晶使用位置、显著提高模糊或折射强度时，需要新的设计评审和性能门禁；
- 此前关于“全面去玻璃”的文档属于已撤销探索，保留在历史记录中仅供追溯。

## 后续动作

1. 保存 Web 七个业务页面、Agent 抽屉和关键烟晶组件的 390 × 844px 基准截图；
2. 建立烟晶组件跨端映射表，记录正常态、降级态和性能预算；
3. 将确认后的颜色、透明度、圆角、边界、阴影和动效转换为机器可读 Token；
4. 在 ArkUI “今日”Walking Skeleton 中验证安全区、底部导航、Agent 入口和烟晶降级。
