这份方案形成于旧原型阶段，包含 Web 参考页、烟晶材质、底部导航、独立 Agent 和多平台扩展等已取消或延期的假设。完整原文保留在[文档归档](../archive/documentation-2026-08-24/docs/architecture/跨平台客户端迁移方案.md)中，只供追溯。

## 现行口径

- 产品语义、流程、领域和验收以 [`docs/product/`](product/README.md) 为准。
- 当前可运行原型位于 `prototype/`，只设计移动端，使用本地 Mock 数据，禁止接入 `server/`。
- `admin/` 是旧原型代码，只供梳理原有视觉与交互，不再承接新原型开发。
- 当前视觉以 [`prototype/DESIGN.md`](../prototype/DESIGN.md) 为准：纯黑屏内背景、编辑式极简排版、纯色色块和细线。
- 当前原型没有桌面版、常驻底部导航、Profile 入口或悬浮 Agent，也不使用环境光、渐变、投影、模糊和玻璃材质。
- 正式产品仍由 `entry + server` 实现和验收。
