# 产品定义与术语

> 状态：已确认
>
> 更新日期：2026-08-24

## 1. 产品定位

`loci` 是一个个人学习 Agent。它把用户提供的资料转化为可阅读、可验证、可追溯的学习项目，并根据学习证据持续建议下一步。

它不是文件管理器、摘要生成器、单文档聊天壳、知识图谱展示工具，也不是以积分和连续打卡驱动的学习产品。

工程仓库和服务可使用 `HarmonyAgent` 作为代号；用户界面、产品文案和对外材料统一使用小写 `loci`。

## 2. 首版价值闭环

> 选择资料 → 设定学习目标 → 确认学习方案 → 阅读与提问 → 测验或费曼讲述 → 形成学习证据 → 获得下一步推荐

首版成功不以生成多少内容为标准，而以用户能否完成这条闭环并理解每一步依据为标准。

## 3. 用户侧核心对象

| 名称 | 用户理解 | 不应出现的混用 |
| --- | --- | --- |
| 学习项目 | 围绕一份资料和一个目标持续进行的学习 | 不称“文件任务”“Book 任务” |
| 学习书 | 学习项目中的主要学习载体，包括方案、章节、正文和概念图 | 不等同于原始文件 |
| 章节 | 学习书内可独立阅读和验证的单元 | 不称“卡片组” |
| 来源资料 | 用户导入、可定位和引用的原文 | 不作为学习库中的独立项目 |
| 今日推荐 | 系统建议用户现在完成的一项学习行动 | 不承载文件处理状态 |
| 项目通知 | 解析、生成、失败和恢复等项目状态提示 | 不参与掌握判断 |
| Chat | 有明确作用域的学习助手 | 不称独立知识库或第四个 Tab |
| 概念图 | 当前学习书中的知识关系视图 | 不称全局知识地图 |
| 学习证据 | 由正式学习行为产生、可回到原始事件的判断依据 | 不等同于浏览、停留或聊天记录 |
| 复习任务 | 围绕少量概念的短学习任务 | 不作为新的一级页面 |

## 4. 后端核心对象

| 对象 | 事实职责 | 用户侧投影 |
| --- | --- | --- |
| `LearningProject` | 聚合目标、来源、学习书和生命周期 | 学习项目 |
| `Document` / `DocumentUnit` | 保存来源资料及可定位单元 | 来源资料、原文查看器 |
| `SourceAnchor` | 定位页、章节、段落或文本区间 | 引用跳转 |
| `Book` / `Chapter` / `Block` | 保存学习书结构、内容与生成状态 | 学习书、章节正文 |
| `Conversation` / `Message` | 保存 Chat 会话、消息和作用域 | Chat 历史 |
| `LearningEvent` | 保存不可变的原始学习行为 | 答题、讲述、复习记录 |
| `LearningEvidence` | 对事件作出的结构化评价 | “为什么这样判断” |
| `Concept` / `ConceptRelation` | 保存概念及有语义、有依据的关系 | 概念图 |
| `ConceptState` | 保存用户对概念的学习状态投影 | 未验证、学习中、已掌握、待复习 |
| `ReviewItem` | 保存复习目标和调度信息 | 今日复习推荐 |
| `TodayRecommendation` | 保存一项可解释的学习建议 | 今日主推荐或备选 |
| `ProjectNotice` | 保存需要用户知晓或处理的项目状态 | 横幅、角标、通知 |

`LearningProject` 是产品层聚合对象，不要求首个代码提交立即增加同名数据库表。现有 `Document` 与 `Book` 可以先通过稳定关联和聚合 DTO 对外提供同一项目视图。

## 5. 首版内容块口径

生成式章节首版只承诺六类教学语义：

1. 讲解；
2. 示例；
3. 公式或关键结论；
4. 引用；
5. 小测；
6. 费曼讲述。

现有 `callout` 是展示样式，不是新的领域类型；`figure` 是讲解或示例的附件；`user_note` 是用户标注；`flash_cards` 属于复习表现形式。它们不得扩大首版生成合同。

## 6. 状态词汇

实现状态统一使用：

- `Prototype`：已有页面或实验链路，尚未完成真实端到端验收；
- `Integrated`：客户端和服务端已按契约接通；
- `Verified`：使用真实资料、真实模型和目标设备完成验收；
- `Planned`：已确认需求，尚未实现；
- `Deferred`：当前阶段明确不做。

用户界面不得直接展示这些工程词汇，应改写为用户能行动的状态，如“正在生成第一章”“可以继续阅读”“生成失败，重新尝试”。

## 7. 文案原则

- 用“项目”指代用户持续学习的对象，用“资料”指代来源，用“学习书”指代生成后的学习载体。
- 用“依据”“来源”“证据”说明系统为何得出结论。
- 不使用“已完全掌握”“精准了解你”“知识永不出端”等无法兑现的绝对表述。
- 错误文案必须说明发生了什么、已保留什么、用户现在可以做什么。
- 一个页面只设置一个最高优先级动作。
