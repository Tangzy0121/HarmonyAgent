# loci 最小学习 Agent MVP 范围

状态：集成冻结（Draft）  
适用分支：`integration/minimal-learning-mvp`

本文档只回答首版“必须能做什么”和“明确不做什么”。当历史方案、页面占位文案或旧分支与本文冲突时，以本文为本次 MVP 集成边界。

## 一条首版主流程

1. 用户导入一份 PDF、Markdown 或 DOCX 资料；
2. 服务端解析资料并返回可追溯的文档记录；
3. 用户填写学习目标与当前水平，生成学习书提案；
4. 用户确认或调整目录，按章生成互动学习内容；
5. 用户阅读章节，完成测验或费曼解释；
6. 系统记录进度、学习证据并给出复习建议；
7. 知识地图展示当前学习书中的概念与关系；
8. 用户可以向 Agent 自由提问，但默认上下文限定为当前学习书或当前章节。

任何不能直接服务这条流程的能力，首版不继续扩展。

## 首版必须保留

| 能力 | 首版定义 | 能力边界 |
| --- | --- | --- |
| 资料导入 | PDF、Markdown、DOCX 上传、解析、列表与删除 | 单文件不超过 20 MB；不含 EPUB、网页抓取、图片 OCR |
| 互动学习书 | 创建提案、用户确认、按章生成、章节阅读 | 一份资料生成一本学习书；不做多资料合并 |
| 测验与费曼学习 | 章节测验作答、反馈、费曼解释评价 | 只基于当前书内容；不做独立题库和复杂自适应组卷 |
| 复习与学习证据 | 到期复习、作答/解释证据、学习者概况 | 证据只由明确的学习动作产生；自由聊天不更新掌握状态 |
| 阅读进度 | 访问章节、书签、完成度、薄弱章节提示 | 首版使用简单可解释规则，不引入推荐模型 |
| 知识地图 | 投影当前学习书中的概念和关系 | 是学习书的只读投影，不是独立知识图谱或全库图数据库 |
| 通用 Agent | 自由提问、当前书/章节上下文、引用来源 | “通用”指问题类型不限，不代表默认检索整个资料库；无选中资料时要求用户先选择范围 |
| HarmonyOS 客户端 | HTTP Repository、Agent Gateway、基础学习页面 | `FIXTURE` 只用于离线演示；HTTP 联调时显式切换配置并填写设备可访问的服务地址 |

## 暂不纳入首版

- EPUB、网页、图片、OCR、音视频等额外输入；
- 多资料合并成书、知识空间编排、跨库检索；
- 独立题库、复杂自适应测验、学习前测分支；
- 正式向量 RAG、图数据库、自动知识图谱维护；
- 账户注册、登录、多租户、权限分享；
- 对象存储、正式数据库、云同步和生产部署；
- 小艺、A2A、通知、语音等系统连接器的产品化扩展。

相关代码可以暂时保留用于兼容或后续研究，但不得成为首版主流程的必经步骤，也不再为其增加页面入口。

## 当前 API 集成基线

以下接口作为本次 Web、HarmonyOS 与服务端联调的临时基线；字段可以在 Draft 阶段修正，但修改必须同步客户端、测试和本文档。

| 场景 | 接口 |
| --- | --- |
| 资料 | `POST/GET /api/documents`、`DELETE /api/documents/:id` |
| 学习书 | `POST/GET /api/books`、`GET/DELETE /api/books/:id` |
| 提案与章节 | `POST /api/books/:id/confirm`、`POST /api/books/:id/chapters/:cid/generate` |
| 测验与费曼 | `POST /api/books/:id/attempts`、`POST /api/books/:id/chapters/:cid/feynman` |
| 进度与复习 | `POST /api/books/:id/progress`、`GET /api/books/:id/completion`、`GET /api/books/:id/review/due` |
| 学习证据 | `GET /api/learner/profile`，证据写入由测验、费曼和复习流程触发 |
| Agent | `POST /api/agent/turns`、`GET /api/agent/turns/:turnId/events`、回答与取消接口 |

这些接口不是生产 API 冻结。首版仍是单用户本地原型，默认身份为 `local-user` / `local-workspace`，数据保存在服务端本地目录。

## Agent 能做与不能做

Agent 可以：

- 读取当前资料片段和当前学习状态；
- 对当前书或章节进行解释、归纳、举例和问答；
- 在引导学习中批改测验、评价费曼解释、记录证据和安排复习；
- 明确展示本轮使用的上下文与来源。

Agent 不可以：

- 在没有当前资料依据时伪造引用；
- 因一次自由聊天直接修改掌握度或生成学习证据；
- 默认读取所有资料或执行跨用户操作；
- 执行文件系统、网络、账户或任意代码操作；
- 把模型输出当成已经确认的学习事实。

## Draft 验收门槛

- [ ] PDF、Markdown、DOCX 各完成一次“上传 → 解析 → 创建学习书”；
- [ ] 提案可以确认，至少一章可以生成并重新打开；
- [ ] 一次测验和一次费曼解释可以形成可查询的学习记录；
- [ ] 章节访问、书签、完成度和到期复习可以持久化；
- [ ] 地图只展示当前真实学习书的概念投影，不把示例数据伪装成用户数据；
- [ ] Agent 在书级和章节级上下文下各完成一次对话，并返回可见来源；
- [ ] Web 前端可以完成主流程；
- [ ] HarmonyOS 在 `HTTP` 模式下可以连接可访问的后端地址并完成核心读取/交互；
- [ ] `server` 与 `admin` 的测试、构建通过；HarmonyOS 工程通过 DevEco Studio 构建；
- [ ] 未配置模型、网络失败、解析失败时有明确错误态，不静默回退为真实结果。
