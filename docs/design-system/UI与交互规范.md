# UI 与交互规范 V1.1

**状态：** 当前有效基线

**基准实现：** `admin/` 第三批移动端高保真原型，390 × 844px 标准视口

## 1. 文档目的

本文档用于定义知识管理 Agent 的页面骨架、组件行为、操作反馈、手势规则、响应式适配与关键任务流，并作为低保真原型、高保真设计、前端实现和交互验收的共同依据。

本文档承接：

- 《用户旅程.md》：定义用户为什么进入页面、完成什么任务；
- 《视觉设计规范.md》：定义产品气质、排版、色彩、材质与动态语言；
- 《信息架构与页面结构.md》：定义核心对象、页面职责与跨页面上下文。

本文档不重新讨论产品定位，也不替代视觉规范。它重点回答：

1. 页面和组件在不同状态下如何工作；
2. 用户操作后系统如何响应、反馈和归位；
3. 今日、学习、知识库和自由 Agent 的边界如何落实到界面；
4. S01—S10 首次旅程需要哪些页面状态；
5. 移动端、平板和桌面端如何保持同一套交互逻辑。

文中数值分为两类：

- **基线规则**：组件层级、操作逻辑、状态边界等，首版应遵循；
- **首版建议**：尺寸、时长、阈值等，用于建立原型，需经过真机测试后定稿。

## 2. 当前版本基准

### 2.1 全局产品骨架

本规范以后续用户旅程与视觉设计决策为准，当前全局入口为：

> **今日｜学习｜知识库 + 独立 Agent 入口**

| 入口 | 核心问题 | 主要内容 | 不承担的职责 |
|---|---|---|---|
| 今日 | 我现在最值得做什么？ | 一个主要行动、待复习、继续学习、资料处理状态、近期成果 | 全量资料管理、完整地图、开放式长对话 |
| 学习 | 我的知识如何形成、连接并发生变化？ | 学习地图、学习状态图层、深入学习、学习记录 | 原始文件管理、跨全库自由问答 |
| 知识库 | 我保存了什么，可以从哪里追溯？ | 知识空间、文件列表、理解结果、正文与引用定位 | 判断掌握状态、展示完整学习过程 |
| Agent | 我现在想问什么或让系统协助什么？ | 跨知识点、跨资料问答，上下文管理，转入深入学习 | 自动替代学习闭环、未经证据更新掌握状态 |

### 2.2 当前容器边界

四个核心容器已统一为：

- “今日”以一个当前行动和近期变化形成日常入口；
- “学习”以连续知识地图承担关系探索；
- “知识库”以编辑式特写与列表承担资料管理；
- Agent 通过独立圆形入口打开约 75% 抽屉，可继续吸附到全屏；
- 节点信息面板固定为约 30%，不复用 Agent 的 75% / 全屏规格。

《视觉设计规范.md》《信息架构与页面结构.md》《用户旅程.md》已与此边界同步，设计与开发不得再引用旧导航或旧抽屉结构。

### 2.3 首版设计基准

- 移动端优先；
- 底部导航常驻，Agent 入口与其并列但独立；
- 页面共享固定雾银底图、烟灰遮罩和近白内容，不再为每个页面切换独立主题；
- 页面内容以开放排版、稳定烟灰表面和编辑式构图为主；
- 导航、搜索、焦点任务、地图命令面板、输入和 Agent 抽屉使用局部 Liquid Glass；
- 桃色用于 `loci`、Agent、当前行动、选中和近期变化，普通功能图标保持单色；
- 图标统一使用单色 SVG，禁止用 Unicode 字符代替产品图标；
- 地图与抽屉承担主要空间交互；
- 任何 AI 判断都需要可见依据、可修正入口和明确状态。

## 3. 页面与容器模型

### 3.1 四类界面容器

| 类型 | 行为 | 典型场景 |
|---|---|---|
| 一级页面 | 保留各自滚动、筛选和视口状态；底部导航可见 | 今日、学习、知识库 |
| 任务页 | 聚焦单一任务；可临时隐藏底部导航 | 上传、归属确认、深入学习、文件正文 |
| 上拉抽屉 | 保留后方上下文；支持 75% 与全屏吸附 | Agent |
| 地图信息面板 | 保留大部分画布；稳定在约 30% | 知识节点概要与导航 |
| 系统浮层 | 处理短决策或短反馈；不承载长内容 | 菜单、确认、Toast、权限说明 |

### 3.2 页面状态保留

用户在一级页面之间切换时，默认保留：

- 今日的滚动位置与展开状态；
- 学习地图的视口、缩放、筛选、图层和当前范围；
- 知识库的知识空间范围、搜索词、筛选和滚动位置；
- Agent 抽屉关闭前的会话与高度状态。

以下情况允许重置：

- 用户主动点击已选中的底部导航项：返回该一级页面默认焦点；
- 用户明确选择“清除筛选”或“回到全局视图”；
- 当前对象已经删除或失效；
- 深链明确要求进入特定对象和状态。

### 3.3 返回规则

返回优先级：

1. 关闭当前菜单或轻浮层；
2. 抽屉从全屏回到 75%；
3. 抽屉从 75% 关闭；
4. 退出任务页，返回进入来源；
5. 回到当前一级页面的上一级状态；
6. 离开 App。

系统返回、左上角返回和向下关闭手势必须产生一致结果。任务中存在未保存输入时，需要先保存草稿或提示用户确认。

## 4. 响应式布局基线

### 4.1 断点建议

| 设备范围 | 建议断点 | 网格 | 页面边距 | 主要形态 |
|---|---:|---:|---:|---|
| 紧凑移动端 | `320–369px` | 4 栏 | 16px | 单列、底部导航、全宽任务页 |
| 标准移动端 | `370–480px` | 4 栏 | 20px | 当前首要设计与实现基准 |
| 原型展示容器 | `> 480px` | 保持移动宽度 | 居中 | Web 原型居中显示移动 App，不扩张成桌面后台 |
| 平板与桌面 | 后续单独定义 | 待定 | 待定 | 不从当前移动样式机械拉伸 |

断点服务于内容和操作方式，不以具体设备品牌为依据。

### 4.2 安全区域

- 顶部内容避让系统状态栏与挖孔区域；
- 底部导航、Agent 入口和输入框叠加 `safe-area-inset-bottom`；
- 页面底部滚动留白应包含导航高度、悬浮间距与安全区域；
- 键盘弹出时，输入框始终可见，不能被导航或系统键盘遮挡。

### 4.3 内容宽度

- 普通移动端内容可跨页面有效宽度；
- 学习正文与长文阅读在平板/桌面端建议限制在 `640–760px`；
- 对话正文在桌面端建议限制在 `720–840px`；
- 知识库列表可扩展至 `960–1120px`；
- 地图画布占满可用视口，不受正文最大宽度限制。

### 4.4 触控目标

- 主要触控目标最小 `44 × 44px`；
- 图标可见尺寸可以为 `20–24px`，但点击区域不得随之缩小；
- 相邻触控目标之间至少保留 `8px` 有效间距；
- 拖拽把手不是唯一入口，必须同时支持点击或按钮操作。

## 5. 全局导航与公共入口

### 5.1 底部导航胶囊

内容顺序：

> 今日｜学习｜知识库

首版建议：

- 高度：`66px`；
- 单项最小点击宽度：`64px`；
- 距屏幕左右：`16–20px`；
- 距安全区顶部：`8–12px`；
- 使用烟灰折射 Liquid Glass，不与稳定资料行共用材质；
- 每一项始终同时展示统一单色 SVG 图标与文字标签。

状态：

| 状态 | 反馈 |
|---|---|
| 默认 | 次级文字，对比度仍满足可读性 |
| 选中 | 近白实体选中面，图标与文字使用深烟灰 |
| 按下 | 轻微下沉，不缩放整个导航 |
| 切换 | 选中标记沿内部吸附到目标，页面内容同步切换 |
| 键盘弹出 | 对话与输入型页面收起；非输入场景按平台规则避让 |

选中面沿导航内部吸附到目标，只能使用近白实体；不得使用桃色、冷紫胶囊或多层彩色嵌套。

### 5.2 Agent 圆形入口

- 位于底部导航右侧或与导航整体形成平衡关系；
- 视觉上略厚于导航，但不大于一级导航整体权重；
- 可见直径 `66px`，触控区域不得小于可见面积；使用桃色实体圆形；
- 内部使用桃花标识；闭合态保持稳定，不持续旋转或发光；
- 按下时轻微下沉，释放后带出 Agent 抽屉；
- Agent 打开后，图标切换为明确的收起或关闭含义；
- 不使用机器人头像、魔法棒、Emoji、粒子群或霓虹外发光。

Agent 入口默认携带当前页面作为弱上下文，但不能在用户不知情时把整页内容永久加入会话。

### 5.3 顶部栏

一级页面顶部栏可包含：

- 页面标题或当前范围；
- 搜索；
- 通知；
- 头像与个人设置。

规则：

- 同一页面最多保留一个高频主入口和两个次级图标入口；
- 页面滚动后可压缩顶部栏，但必须保留当前范围与返回语义；
- 地图页顶部控制应悬浮在画布上，不占用固定大标题区；
- 任务页使用返回 + 任务名称，不同时展示完整一级导航。

### 5.4 全局搜索

搜索对象包括知识空间、文件、知识节点和对话记录。首版结果按对象类型分组。

- 输入后 `150–250ms` 防抖；
- 空输入展示最近访问或最近搜索，不展示无关推荐；
- 结果必须标明类型与所属空间；
- 选择文件进入文件详情；
- 选择节点进入学习地图并聚焦节点；
- 选择对话恢复对应 Agent 会话；
- 无结果时提供修改关键词、清除筛选或向 Agent 提问三类出口。

## 6. 基础交互状态

### 6.1 通用状态集合

所有可交互组件应根据需要覆盖：

- 默认；
- 悬停（支持鼠标时）；
- 按下；
- 键盘聚焦；
- 选中；
- 禁用；
- 加载；
- 成功；
- 错误。

不得只在设计稿中提供默认状态。

### 6.2 聚焦状态

- 键盘聚焦必须清晰可见；
- 聚焦环不得被玻璃模糊、容器裁切或阴影遮盖；
- 聚焦顺序遵循视觉阅读顺序；
- 抽屉打开后焦点进入抽屉，关闭后回到触发入口；
- 地图节点支持键盘顺序访问，并提供跳过地图进入控制区的方式。

### 6.3 加载与处理中

| 时长预期 | 反馈方式 |
|---|---|
| `< 300ms` | 通常无需显示加载反馈 |
| `300ms–2s` | 局部结构占位或控件加载态 |
| `2–10s` | 展示当前阶段与可取消/离开说明 |
| `> 10s` | 允许离开，后台继续，完成后通知 |

AI 处理不得只显示无期限旋转。需要展示真实阶段，例如“正在解析文件”“正在识别主题”“正在生成理解结果”。

### 6.4 成功反馈

- 轻量操作：控件自身状态变化或短 Toast；
- 影响页面结构的操作：直接展示结果，无需额外 Toast；
- 安排、删除、移动等重要操作：显示对象、结果和可撤销入口；
- 学习完成：展示成果归拢与下一出口，不使用庆祝动画。

### 6.5 错误反馈

错误信息至少回答：

1. 发生了什么；
2. 哪些内容已经保留；
3. 用户现在可以做什么。

字段错误显示在字段附近；任务级错误显示在任务内容区；系统级错误才使用全页状态。不能用 Toast 承载需要用户阅读或处理的重要错误。

## 7. 基础组件

### 7.1 按钮

| 类型 | 使用场景 | 形态 |
|---|---|---|
| 主按钮 | 页面唯一最高优先级动作 | 近白实体、深烟灰文字，20px 圆角 |
| 次按钮 | 次级出口、替代选择 | 透明或浅底，细边界 |
| 文字按钮 | 低风险辅助操作 | 文字 + 可选图标，无容器 |
| 危险按钮 | 删除、清除、退出 | 默认克制，仅在确认阶段增强警示 |
| 图标按钮 | 搜索、关闭、更多 | 固定触控区域，必须有可访问名称 |

规则：

- 每个页面或抽屉视口原则上只有一个主按钮；
- 按钮文案使用结果导向动词，如“开始深入学习”“安排到明天”；
- 不使用含糊的“确定”“好的”，除非上下文结果已经极其明确；
- 加载时保留原按钮宽度并防止重复提交；
- 禁用原因可通过邻近说明或点击后解释，不能让用户无从判断。

首版尺寸建议：

- 大按钮：高 `52px`；
- 标准按钮：高 `44–48px`；
- 紧凑按钮：高 `36–40px`，仅用于桌面或非主要操作；
- 水平内边距：`16–24px`。

### 7.2 输入框与文本域

- 标签常驻，不只依赖占位符；
- 占位符只说明示例，不承担字段名称；
- 支持清除、错误说明和字符限制时，需要保留稳定位置；
- 输入区域聚焦时通过边界与轻微底色变化反馈，不使用强发光；
- 多行输入自动增长至上限，超过后内部滚动；
- Agent 输入框支持附件、上下文与发送，但不把三者塞入同一模糊图标。

### 7.3 搜索框

- 高度建议 `44–48px`；
- 输入时可直接显示结果；
- 有筛选生效时，搜索框附近显示筛选数量；
- 清除搜索只清除关键词，不默认清除范围和筛选；
- 移动端进入沉浸式搜索后保留明确退出动作。

### 7.4 标签与上下文标签

标签至少区分：

- 分类标签：用文字、轮廓和空间位置表达知识类别；
- 筛选标签：表达当前筛选；
- 上下文标签：表达 Agent 正在优先参考的对象；
- 状态标签：表达处理或确认状态。

上下文标签必须支持查看来源与移除。移除当前文件后，界面需明确会话是否仍参考全知识库或完全不引用资料。

### 7.5 分段控制与筛选器

- 分段控制只用于 2–3 个互斥且同层级的视图；
- 不用分段控制替代一级导航；
- 筛选条件超过 3 个时使用筛选抽屉；
- 筛选结果即时预览，复杂筛选可使用“应用”；
- 始终提供“清除”与当前生效数量；
- 切换学习地图图层不应重置视口。

### 7.6 列表行

列表行可包含：

- 主标题；
- 一行或两行摘要；
- 对象类型、空间、时间或状态；
- 可选缩略图；
- 行尾进入或更多操作。

规则：

- 整行可点击时，内部次级操作需避免手势冲突；
- 开放列表默认使用细分隔线；知识库资料行允许使用无阴影的稳定烟灰圆角表面；
- 状态信息位置保持一致；
- 滑动操作只作为快捷方式，并提供菜单替代入口；
- 删除、移动和多选需要进入明确模式，避免误触。

### 7.7 引用与来源

- 引用在回答、理解结果和学习内容中使用统一编号或来源标记；
- 点击引用先打开来源预览抽屉；
- 用户可继续进入知识库正文的精确位置；
- 来源预览至少显示文件名、所属空间、页码/段落和相关原文；
- 无法精确定位时必须明确写出“来源范围”，不能伪造精确页码；
- 生成内容与原文摘录在排版上可辨别。

### 7.8 进度表达

- 文件处理：阶段式进度；
- 上传：可使用确定进度条；
- 深入学习：使用阶段名称与已完成步骤，不使用游戏化进度环；
- 掌握状态：基于证据说明，不展示无法解释的单一百分比；
- 预计时间只是参考，不倒计时施压。

### 7.9 Toast、横幅与确认对话框

| 组件 | 用途 | 不适用 |
|---|---|---|
| Toast | 短暂、可忽略、无需决策的结果 | 错误详情、删除确认、长文案 |
| 页面横幅 | 持续状态、离线、处理中、权限受限 | 单次成功反馈 |
| 确认对话框 | 不可逆或高影响操作 | 普通导航、可撤销操作 |

删除优先提供撤销；彻底删除文件、清除学习记录等不可恢复操作必须二次确认并说清影响范围。

## 8. 空间组件与手势

### 8.1 上拉抽屉通用结构

抽屉由以下区域组成：

1. 顶部抓手或标题栏；
2. 固定标题与关键操作；
3. 可滚动内容区；
4. 可选底部输入或决策区；
5. 安全区。

以下主要吸附状态只适用于 Agent 抽屉：

- 关闭；
- 默认约 75%；
- 全屏。

首版建议：默认高度为可用视口的 `72%–78%`，最终以内容可见量、地图保留面积和真机手势验证为准。

### 8.2 抽屉手势归属

- 从标题栏或抓手拖动：控制抽屉高度；
- 内容区未滚到顶部时向下滑：优先滚动内容；
- 内容区已到顶部且继续向下：转交抽屉；
- 向上滑时，抽屉未全屏则优先扩展；全屏后滚动内容；
- 地图上的拖拽不得穿透到已打开抽屉；
- 输入框聚焦后，抽屉自动进入接近全屏状态。

释放落点同时参考当前位置与速度。快速明确手势可跨过中间吸附点；慢速手势优先落到最近稳定状态。

### 8.3 阻力与边界

- 抽屉拖动起始设置轻微意图阈值；
- 手势主体保持跟手，不人为延迟；
- 超出全屏或关闭边界时增加渐进阻力；
- 接近关闭边界时保留适度阻力以减少误关；
- 用户快速下甩仍可直接关闭；
- 减少动态模式下保留吸附结果，但取消明显惯性与回弹。

### 8.4 Agent 抽屉

默认约 75%，包含：

- 会话名称或“新对话”；
- 历史记录与新建入口；
- 当前弱上下文标签；
- 消息区；
- 建议问题；
- 固定输入区。

行为：

- 从页面打开时，默认将当前对象作为可移除弱上下文；
- 首次打开不自动发送问题；
- 用户输入后建议问题收起；
- 长对话或键盘弹出时吸附至全屏；
- 关闭后保留会话草稿和原页面状态；
- 切换上下文不删除已经发生的消息，只影响后续回答，并显示分界说明。

### 8.5 节点信息面板

节点详情是地图内的轻量浮动信息面板，默认覆盖约 30% 可用画布，不与 Agent 共用 75% 抽屉规格。内容顺序：

1. 知识点名称与类别；
2. 一句话概要；
3. 所在主题路径；
4. 一阶邻近节点；
5. 深入学习入口；
6. 相关资料与引用；
7. 学习记录或状态依据；
8. 关系修正与更多操作。

节点面板不承载完整课件或长篇正文，也不默认扩展为全屏。点击资料后进入知识库的来源预览或正文位置；需要自由问答时再转换为带当前节点上下文的 Agent 抽屉。

### 8.6 浮层叠加限制

- 同一时刻只保留一个主要 75% 抽屉，当前规格仅用于 Agent；
- 节点面板中唤起 Agent 时，优先转换为 Agent 抽屉，并把当前节点带入上下文；
- 来源预览可以作为抽屉内子层，但不得再出现第三层全尺寸抽屉；
- 二次确认对话框可以覆盖抽屉；关闭后焦点回到原操作；
- 避免“抽屉套抽屉套全屏页”的不可预测返回链。

## 9. 学习地图交互规范

### 9.1 地图职责

学习地图只负责：

- 展示知识 outline；
- 展示节点之间的关系；
- 通过轮廓、位置、连接和标签展示知识类别与当前范围；
- 揭示资料或学习带来的局部变化；
- 作为进入节点信息面板和深入学习的空间入口。

地图不负责：

- 阅读完整资料；
- 直接呈现所有节点详情；
- 仅凭文件存在判断用户已学习；
- 用颜色作为知识类别的唯一主编码，或同时表达类别和掌握状态；
- 把文件作为主要知识节点。

### 9.2 节点语义

- 轮廓、描边形态与文字标签：知识类别；
- 位置：结构与关系距离；
- 面积或大小：结构重要性或当前聚焦权重；
- 连线：前置、包含、相似、对比、应用等关系；
- 青色短期标记或光晕：最近新增、引用或刚建立的关系；
- 学习状态：独立可选图层；绿色表示已掌握，橙色表示待复习，其他状态使用文字与形态说明。

学习状态图层首版只显示：

- 无学习记录；
- 已学习；
- 待复习。

“无学习记录”不得写成“未学习”或“不会”。

### 9.3 基础手势

| 操作 | 结果 |
|---|---|
| 单指拖拽 / 鼠标拖拽 | 平移画布 |
| 双指缩放 / 滚轮缩放 | 围绕手势中心缩放 |
| 点击节点 | 聚焦节点并打开约 30% 高度的节点信息面板 |
| 点击空白 | 取消当前高亮；已开抽屉时不默认关闭 |
| 双击空白 | 首版不绑定关键操作，避免误触 |
| 长按节点 | 打开节点操作菜单或进入关系修正 |
| 框选 | 首版暂缓，避免与拖拽冲突 |

桌面端必须提供可见的缩放控制与“适合当前范围”按钮，不能只依赖滚轮和触控板。

### 9.4 惯性与吸附

- 松手后允许短暂惯性，快速衰减；
- 缩放只吸附到少量语义级别，如概览、主题、节点；
- 主题簇可产生弱吸附，但不得打断明确拖拽；
- 点击节点后，地图把节点移动到抽屉上方剩余画布的视觉焦点，而非屏幕物理中心；
- 关闭抽屉后恢复此前视口，不机械回到全局中心。

### 9.5 聚焦与逐步揭示

聚焦节点后：

1. 当前节点提高对比度；
2. 一阶关系渐进显现或增强；
3. 非相关节点降低存在感但不完全消失；
4. 地图平移至适合抽屉展开的位置；
5. 节点信息面板显示概要与出口。

从抽屉选择邻近节点时，地图焦点与抽屉内容同步过渡，避免先关闭再重新打开造成断裂。

### 9.6 范围、图层与搜索

顶部控制至少包含：

- 当前知识范围；
- 搜索；
- 图层；
- 适合视图；
- 可选的最近变化入口。

规则：

- 更换知识范围可以改变图谱内容；
- 开关图层不能改变节点真实归属；
- 搜索结果在地图上逐个聚焦，并同时提供列表选择；
- 退出搜索恢复此前视口与图层；
- 当前筛选必须可见，并支持一键清除。

### 9.7 首次变化揭示

S09 进入地图时：

- 聚焦本次资料新增的知识斑块；
- 用短期、低强度光晕区分新增节点与联系；
- 本次深入学习形成的证据附着到对应节点；
- 提供“查看这个知识点”“查看来源”“安排下一次”三个层级清晰的出口；
- 不播放自动漫游，不把全部地图压缩进视口。

## 10. 自由 Agent 交互规范

### 10.1 能力边界

自由 Agent 用于：

- 跨知识点和跨资料提问；
- 比较、解释、总结和规划；
- 临时探索尚未形成明确学习目标的问题；
- 建议用户是否进入单知识点深入学习。

自由 Agent 不应：

- 在普通问答后自动宣称用户已掌握；
- 自动把所有回答写入学习记录；
- 用一组验证题把自由问答伪装成学习会话；
- 在未经确认时扩大或永久保存敏感上下文。

### 10.2 上下文模型

界面需要同时区分：

- 当前弱上下文：由当前页面自动带入，可移除；
- 用户主动添加的上下文：文件、节点、空间或临时附件；
- Agent 实际引用的来源：本次回答真正使用的内容；
- 全库能力范围：系统是否允许检索其他个人知识。

推荐表达：

> 优先参考：当前文件 ×　　范围：可检索全部知识

不得用单个“当前文件”标签让用户误以为 Agent 只能回答该文件。

### 10.3 消息与回答

- 用户与 Agent 消息不使用高饱和彩色气泡；
- 长回答使用清晰段落、列表和引用；
- 生成中支持停止；
- 停止后保留已生成内容，并提供继续或重新生成；
- 回答底部提供引用、复制、反馈与继续行动；
- 纠错入口允许用户标记“来源错误”“理解错误”“不符合问题”。

### 10.4 推荐问题

- 首次打开显示 2–3 条，与当前页面和用户任务直接相关；
- 推荐问题以简短文字行呈现，不做大卡片矩阵；
- 用户开始输入后收起；
- 不循环刷新大量问题制造功能感；
- 没有当前上下文时，使用开放输入提示而非泛化模板堆叠。

### 10.5 转入深入学习

当对话收敛到单一知识点并出现明确学习意图时，可以提示：

> 要围绕“监督学习与无监督学习”完成一次约 8 分钟的深入学习吗？

规则：

- 建议不是强制步骤；
- 用户确认后创建独立学习会话；
- 携带知识点、关键解释和相关来源；
- 原对话保留，不自动改写为学习记录；
- 学习完成后可返回原会话，并插入简短完成摘要。

## 11. 深入学习交互规范

### 11.1 单点原则

一次深入学习只围绕一个知识点或一个明确、可在短时间内完成的目标。

如果用户目标过大，系统先拆分并让用户选择当前焦点。不得把完整章节、多个互不相同的概念塞入一次闭环。

### 11.2 首版阶段结构

建议采用：

1. 明确目标；
2. 连接已有认识；
3. 核心解释；
4. 回忆或应用；
5. 简短验证；
6. 结果反馈；
7. 完成摘要与下一出口。

具体步骤可以根据知识类型调整，但必须有可见目标和结束状态。

### 11.3 页面结构

- 顶部：返回、知识点名称、阶段信息；
- 主体：当前解释、材料、问题或练习；
- 来源：就近引用，可展开但不打断主线；
- 辅助入口：向自由 Agent 提问；
- 底部：当前阶段主操作；
- 完成后：证据摘要、状态说明、查看地图、安排下一次。

学习正文采用收窄阅读宽度。底部操作区在键盘出现时需要避让，不遮挡输入答案。

### 11.4 自评与验证

- 自评只能作为证据之一；
- 验证题需要说明答题目的，不营造考试惩罚感；
- 回答错误时解释关键差异，并允许再试或查看来源；
- 无法判断时标记“不确定”，不伪造精确掌握度；
- 用户可查看“为什么系统这样判断”。

### 11.5 中断与恢复

- 离开前自动保存当前阶段和草稿；
- 返回时优先恢复到中断位置；
- 今日显示“继续学习”而不是重新创建任务；
- 资料或来源失效时，保留学习记录并说明缺失部分；
- 用户可主动结束，不将中断等同于失败。

### 11.6 完成与证据归拢

完成后展示：

- 本次理解的知识点；
- 使用了哪些来源；
- 用户完成了哪些回忆或验证；
- 系统记录了什么、没有记录什么；
- 地图中哪个节点发生了变化。

完成页的首要出口根据首次旅程为“查看地图变化”；日常学习可根据进入来源返回今日、地图或原 Agent 会话。

## 12. 知识库与文件交互规范

### 12.1 知识库首页

默认结构：

1. 页面标题与搜索；
2. 当前知识空间范围；
3. 最近使用或待处理；
4. 文件列表；
5. 上传入口；
6. 筛选与排序。

知识空间是主要范围，不建立无限层级文件夹。标签、文件类型和更新时间作为辅助筛选。

### 12.2 知识空间切换

- 默认范围为“全部知识”；
- 当前范围在顶部清晰可见；
- 切换后保留兼容筛选，移除不兼容筛选并说明；
- 创建空间不要求首次填写描述、封面和复杂标签；
- 修改空间不会改变文件原文与学习记录，只更新组织关系。

### 12.3 文件列表

每行建议显示：

- 文件名；
- 所属知识空间；
- 文件类型；
- 更新时间；
- 处理状态；
- 可选的主题摘要。

点击进入文件详情；长按或更多菜单提供移动、重命名、重新解析和删除。批量模式需明确进入和退出。

### 12.4 文件详情 / 理解结果

页面层级：

1. 文件信息与处理状态；
2. 一句话概述；
3. 主题与核心概念；
4. 前置知识；
5. 推荐学习点及依据；
6. 原文预览与引用；
7. 开始深入学习；
8. 向 Agent 提问；
9. 在学习地图中查看；
10. 修正与文件管理。

首次进入默认展示理解结果；用户可切换至原文。理解结果与原文不是两份文件，而是同一文件的两种阅读层。

### 12.5 原文定位

- 从引用进入时直接定位到相关页码或段落；
- 高亮相关范围，但不永久改变原文；
- 返回后恢复此前理解结果或 Agent 对话位置；
- 扫描件无法精确定位时显示页级范围；
- 原文阅读支持搜索、目录和缩放，但首版不承担复杂编辑。

### 12.6 上传任务流

统一流程：

> 选择资料 → 上传 → 解析 → 建议归属 → 用户确认 → 生成理解结果

规则：

- 文件选择后立即显示名称、大小、格式与可移除入口；
- 上传进度可取消，取消前说明已上传部分是否保留；
- 解析阶段允许离开；
- Agent 建议归属必须显示简短依据；
- 用户确认或修改后再建立正式归属；
- 部分解析成功时先展示可用结果，并明确缺失内容；
- 失败后保留文件和已完成阶段，支持重试。

## 13. 今日页交互规范

### 13.1 页面职责

今日是行动决策页，不是信息流或数据仪表盘。页面需要回答：

> 我现在最值得做什么？

### 13.2 信息优先级

1. 一个主要行动；
2. 今日需要处理的复习或继续学习；
3. 文件处理与待确认状态；
4. 近期变化；
5. 次级探索入口。

主要行动必须包含推荐原因，并允许用户换一个建议、稍后安排或拒绝。

### 13.3 新用户空白状态

页面包含：

- 标题：让 Agent 认识你的第一份知识；
- 说明：上传课件、笔记或教材，生成属于你的知识结构；
- 主按钮：上传第一份资料；
- 次入口：体验示例知识空间。

空白状态不展示伪造任务、虚拟统计或不可点击的占位模块。

### 13.4 S10 首次成果与安排

完成首次学习后，今日显示：

- 本次完成的知识点；
- 资料与地图的变化摘要；
- 推荐的下一步及原因；
- 主按钮：安排到明天；
- 次按钮：今天继续；
- 文字入口：暂不安排。

点击“安排到明天”后：

- 显示具体日期与任务摘要；
- 提供短时间撤销或修改；
- 页面进入安静完成状态；
- 不立即生成新的主任务催促用户继续。

### 13.5 拒绝与调整

用户可选择：

- 换一个建议；
- 今天不安排；
- 调整目标；
- 不再推荐此类任务。

询问拒绝原因可以帮助推荐，但必须可跳过；一次拒绝不得被推断为永久偏好。

## 14. S01—S10 页面级规范

### S01 欢迎与注册

**目标**：最短路径建立账号与数据保存能力。

**页面结构**：一句价值主张、注册方式、必要协议、已有账号入口。

**主操作**：继续注册。

**规则**：

- 不在注册前展示完整功能轮播；
- 协议与隐私说明可展开阅读；
- 第三方登录失败后保留已选路径并提供替代方式；
- 注册完成直接进入 S02。

### S02 轻量个性化

**目标**：收集会立即影响体验的少量信息。

**页面结构**：3–4 个问题、步骤提示、跳过、返回。

**主操作**：继续。

**规则**：

- 单页单问题或单页小组问题均可，高保真阶段验证；
- 选项可修改，跳过不制造负面文案；
- 每个问题说明其用途；
- 不收集难以准确自述的复杂认知风格。

### S03 今日空白状态

**目标**：理解第一个有价值的动作。

**主操作**：上传第一份资料。

**次操作**：体验示例知识空间。

**出口**：进入 S04；示例路径不写入个人学习状态。

### S04 上传与解析

**目标**：低成本导入资料并理解处理进度。

**主操作**：选择/确认资料；上传后允许离开。

**关键状态**：待上传、上传中、解析中、部分完成、失败、后台继续。

**出口**：进入 S05；离开后由今日、通知或知识库承接状态。

### S05 归属确认

**目标**：确认资料属于哪个知识空间。

**页面结构**：Agent 建议、判断依据、建议空间、修改入口。

**主操作**：确认归属。

**次操作**：更换或新建知识空间。

**出口**：生成理解结果并进入 S06。

### S06 文件理解结果

**目标**：知道资料讲了什么，并选择下一步。

**页面结构**：概述、主题、核心概念、前置知识、出处、推荐学习点。

**主操作**：开始深入学习。

**次操作**：向自由 Agent 提问；在学习地图中查看。

**出口**：可直接进入 S08，也可经 S07；S07 不是强制步骤。

### S07 自由 Agent（可选）

**目标**：围绕当前文件或全库自由提问。

**容器**：默认约 75% 上拉抽屉。

**上下文**：当前文件为可移除弱上下文，可检索范围单独显示。

**主要操作**：发送问题。

**转换出口**：进入 S08；关闭后返回 S06。

### S08 单知识点深入学习

**目标**：围绕一个知识点完成有开始、有验证、有结束的短闭环。

**页面结构**：目标、解释、回忆/应用、验证、反馈、完成摘要。

**主要操作**：完成当前阶段。

**辅助操作**：查看来源、向自由 Agent 提问、暂时退出。

**出口**：完成后进入 S09。

### S09 查看地图变化

**目标**：理解资料和学习如何沉淀为结构与证据。

**页面结构**：本次新增知识斑块、最近变化提示、节点信息面板入口。

**主要操作**：查看当前节点或继续探索。

**结束出口**：安排下一次，进入 S10。

### S10 今日成果与下一次行动

**目标**：确认成果并自主决定下一步。

**页面结构**：成果摘要、推荐下一步、推荐依据、日期选择。

**主操作**：安排到明天。

**次操作**：今天继续；暂不安排。

**完成状态**：显示“已安排到明天”并安静结束，不追加新任务。

## 15. 响应式行为

### 15.1 移动端

- 底部导航 + 独立 Agent 入口；
- Agent 使用 75% / 全屏上拉抽屉；节点详情使用稳定约 30% 的地图信息面板；
- 学习与正文使用单列；
- 地图控制分布在顶部与侧边，不遮挡底部实体；
- 键盘弹出时输入型抽屉接近全屏。

### 15.2 平板

- 底部导航可保留；横屏时可验证侧边导航；
- 地图与节点详情允许并置，详情宽度约占 `36%–44%`；
- Agent 可转为右侧面板，但保留 75% 抽屉的层级语义；
- 学习正文居中，来源预览可在侧边出现。

### 15.3 桌面端

- 后续桌面形态可验证左侧窄导航或底部悬浮导航；当前阶段不据此改变移动端基线；
- Agent 使用右侧可调整宽度的面板，建议 `400–520px`；
- 节点详情与地图并置，不遮挡关键节点；
- 悬停仅作为补充，所有能力必须可点击获得；
- 地图支持鼠标、触控板和键盘；
- 不把移动端底部抽屉简单拉伸为全宽弹窗。

### 15.4 跨设备连续性

- 保存当前任务、地图范围、学习阶段和 Agent 会话；
- 不要求不同设备恢复到完全相同的像素视口；
- 地图恢复同一知识范围和焦点节点，再根据设备重新适配视口；
- 未发送文本、未提交答案和上传状态应在合理范围内恢复。

## 16. 可访问性

### 16.1 视觉

- 正文与关键控件满足 WCAG AA 对比度目标；
- 状态、关系和选中不能只靠颜色；
- 玻璃背景下的文字具有稳定保护层；
- 文本放大至 200% 时，核心操作仍可用；
- 地图提供列表化替代浏览方式。

### 16.2 动态

系统开启减少动态效果时：

- 取消大范围惯性、视差和弹簧回弹；
- 抽屉直接或短距离切换到吸附状态；
- 地图聚焦使用短距离平移或直接切换；
- 最近变化光晕改为静态边界或标签；
- 功能、焦点与信息不能因减少动态而缺失。

### 16.3 屏幕阅读与语义

- 页面、标题、导航、列表和按钮使用正确语义；
- 图标按钮具有可访问名称；
- 地图节点读出名称、类别、关系数量和学习记录状态；
- AI 生成、原文引用和用户输入具有可区分标签；
- 状态变化通过可访问提示传达，但避免频繁打断。

### 16.4 输入方式

- 所有核心操作支持触控与键盘；
- 不把长按、滑动或拖拽作为唯一操作方式；
- 地图提供可见的缩放、复位和搜索控件；
- 手势冲突时优先保证滚动、返回和输入可用。

## 17. AI 信任、隐私与可修正性

### 17.1 AI 处理边界

- 云端处理前说明发送哪些内容；
- 处理状态显示真实阶段；
- 无资料支持时说明回答来自通用知识；
- 不把模型推断伪装成用户明确事实；
- 证据不足时标记“不确定”。

### 17.2 可追溯

以下内容必须支持查看依据：

- 文件分类建议；
- 核心概念与前置知识；
- Agent 回答；
- 推荐学习顺序；
- 学习状态变化；
- 今日推荐原因。

### 17.3 可修正

用户可修正：

- 文件归属；
- 知识点名称与类别；
- 节点关系；
- 来源错误；
- 学习状态；
- 推荐偏好。

修正后应说明影响范围，并保留必要的版本或撤销能力。一次修正不能被静默推断为永久全局规则。

### 17.4 删除与数据控制

- 删除文件前说明是否影响知识节点、引用和历史学习记录；
- 删除知识节点前说明来源文件是否保留；
- 用户可选择仅移除生成结果、仅移除文件或彻底删除相关数据；
- 不可逆操作需要二次确认；
- 可恢复操作优先提供撤销。

## 18. 首版交互参数建议

以下参数仅用于原型起点：

| 项目 | 首版建议 | 验证重点 |
|---|---:|---|
| 基础间距 | 4px | 是否形成稳定节奏 |
| 页面左右边距 | 20px | 小屏与大屏呼吸感 |
| 最小触控目标 | 44px | 真机误触率 |
| 标准按钮高度 | 48px | 中文文案与可达性 |
| 底部导航高度 | 66px | 与 Agent 入口同高 |
| Agent 入口直径 | 66px | 桃色独立入口，与导航整体平衡 |
| 标准输入框高度 | 48px | 标签与错误态容纳 |
| 抽屉默认高度 | 72%–78% | 后方上下文是否足够可见 |
| 普通反馈时长 | 150–220ms | 是否干净利落 |
| 控件吸附时长 | 180–300ms | 是否精确而不玩具化 |
| 抽屉/地图过渡 | 300–500ms 或物理弹簧 | 阻尼、重量与跟手性 |
| 搜索防抖 | 150–250ms | 输入流畅与请求频率 |
| Toast 停留 | 2.5–4s | 文案可读与不打扰 |

物理动画不得只按时长实现。抽屉和地图需要基于速度、距离、边界和吸附点计算。

## 19. 设计与开发验收清单

### 19.1 全局

- [ ] 一级导航是否统一为“今日｜学习｜知识库”？
- [ ] Agent 是否作为独立入口，而非第四个一级页面？
- [ ] 一级页面切换是否保留各自状态？
- [ ] 返回、关闭和系统返回是否一致？
- [ ] 页面是否只有一个最高优先级操作？

### 19.2 组件

- [ ] 所有可交互组件是否具备必要状态？
- [ ] 触控区域是否至少 44px？
- [ ] 键盘焦点是否清晰且不被裁切？
- [ ] Liquid Glass 是否只用于控制、明确焦点与 Agent 浮层，没有扩散到正文和所有普通列表？
- [ ] 图标是否统一使用同一语言的单色 SVG，而不是字符图标？
- [ ] 禁用、错误和选中是否不只依赖颜色？

### 19.3 抽屉与手势

- [ ] Agent 的 75% 与全屏吸附是否稳定可预期？
- [ ] 节点信息面板是否保持约 30% 的稳定高度，并且不遮断地图探索？
- [ ] 内容滚动与抽屉拖拽是否正确交接？
- [ ] 键盘弹出后输入框是否仍可见？
- [ ] 快速下甩是否可关闭，慢速拖动是否不会误关？
- [ ] 关闭后是否恢复原页面视角与焦点？

### 19.4 学习地图

- [ ] 知识类别是否由轮廓、描边形态、位置与标签共同表达？
- [ ] 辅助色是否只用于学习状态、关系变化和必要语义？
- [ ] 学习状态是否作为独立图层？
- [ ] “无学习记录”是否未被误写为“未学习”？
- [ ] 点击节点后是否聚焦到抽屉上方可见区？
- [ ] 是否提供非手势缩放、搜索与列表替代入口？
- [ ] 文件是否只作为来源，而不是主要地图节点？

### 19.5 Agent 与深入学习

- [ ] 当前弱上下文、检索范围和实际引用是否可区分？
- [ ] 自由问答是否不会自动更新掌握状态？
- [ ] 转入深入学习是否需要用户确认？
- [ ] 深入学习是否聚焦单一知识点并有明确结束状态？
- [ ] 学习结果是否说明使用了哪些证据？

### 19.6 S01—S10

- [ ] S07 是否为可选路径，而不是首次旅程强制步骤？
- [ ] S06 是否可以直接进入 S08？
- [ ] S09 是否展示地图变化，而不是学习后才首次生成地图？
- [ ] S10 是否默认“安排到明天”？
- [ ] 安排完成后是否安静结束，而非立刻追加任务？

### 19.7 视觉降级与无障碍

- [ ] 低性能设备关闭实时模糊后是否仍保持层级？
- [ ] 减少动态模式是否完整可用？
- [ ] 文本放大和屏幕阅读是否不破坏任务流？
- [ ] 地图是否提供列表化替代浏览？
- [ ] 长处理是否允许用户离开并在完成后恢复？

## 20. 待高保真与真机验证

以下内容在 V1.0 中继续通过高保真与真机反馈微调，但不得改变已经确认的设计方向：

1. 底部导航与 Agent 入口在不同视口下的精确间距；

4. 地图缩放级别、惯性衰减和主题簇弱吸附范围；
5. 地图节点采用烟灰形态、状态轮廓、标签或混合形态；
6. 深入学习采用单页阶段流、对话式推进或混合形态；
7. Agent 输入区的附件、上下文与发送操作布局；
8. 平板横屏和桌面端采用侧栏还是保留底部导航；
9. 来源预览使用抽屉内子层还是侧边面板；
10. 首次个性化采用单页单问题还是轻量分组；
11. Liquid Glass 在 ArkUI 与低性能设备上的等价材质和降级阈值；
12. 真实知识数据下节点类别与学习状态两套编码的辨识度。
