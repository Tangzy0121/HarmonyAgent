# 森林绿光照系统试点计划

**日期：** 2026-07-24

**状态：** 已结束，方案未采纳

**试点页面：** 知识库

> 2026-07-24 视觉复核后，森林绿环境色削弱了原有黑白界面的张力。本方案停止扩展，材质结构与主光方向转入中性侧光试点。

## 1. 已确认方向

本轮采用森林绿作为 loci 的环境光色，不把绿色直接铺成实体品牌色，也不使用双色渐变。页面仍以近白内容面和近黑文字建立主要秩序，森林绿通过背景光场、边缘透射、环境阴影和少量交互面进入界面。

深色交互面不再使用纯黑，统一改为低彩度炭灰森林绿。文字与正文继续保持近黑色，避免整页被染色后失去编辑式层级。

## 2. 材质原则

1. 背景使用低饱和森林绿环境光，主光方向固定为左上。
2. 内容列表保持稳定实体表面，不把正文容器改成装饰性玻璃。
3. 搜索、筛选、底部导航和 Agent 等悬浮控制使用清透玻璃。
4. 重点资料区通过边缘高光、接触阴影和远距离环境阴影建立纵深，不使用错位或旋转制造材质。
5. 深色按钮、选中态和重点图形统一使用炭灰森林绿。
6. 状态与操作不能只依赖绿色表达，继续保留文字、图标和形态。

## 3. 试点范围

- 知识库页面背景光场；
- 本周重点资料区；
- 搜索与资料筛选；
- 资料列表内容面；
- 底部导航和 Agent 启动按钮；
- 页面中现有深色交互面。

不修改知识库的信息结构、模拟数据、筛选逻辑、资料入口和页面跳转。

## 4. 验收标准

1. 页面仍然首先被识别为移动端知识应用，而不是展示型网页。
2. 森林绿提供环境氛围，但不降低正文对比度。
3. 白色内容面与背景之间存在明确纵深。
4. 深色按钮与森林绿背景协调，不出现突兀纯黑贴片。
5. 玻璃只用于控制层，列表阅读区域保持稳定。
6. 390 × 844 和不超过 375px 的小屏视口无横向溢出。
7. 搜索、筛选、资料打开、底部导航和 Agent 入口保持可用。
8. TypeScript 与 Vite 生产构建通过。
