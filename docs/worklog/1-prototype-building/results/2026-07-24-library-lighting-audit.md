# 知识库光照系统审查

## 审查范围

- 页面：知识库首页
- 状态：`neutral-light`
- 证据：[当时页面截图（初版归档）](../../archive/prototype-building-original-monochrome/2026-07-24-library-lighting-audit.png)

## 结论

光照不明显不只是阴影太淡。当前主要问题是环境光过宽、卡片表面接近不透明、边缘高光过于均匀，导致页面呈现为统一的浅灰白，而不是由左上方光源塑造出的空间。

## 主要发现

1. 主卡片已有明显投影，但 `22px 54px / 12%` 与 `46px 88px / 5%` 两层阴影半径较大，形成的是均匀雾状悬浮感，方向性不足。
2. 左上白色背景光覆盖范围过大，页面上半部整体被提亮，卡片与背景的受光差异被抹平。
3. 卡片表面透明度较高，背景纹理与色差几乎无法穿透，玻璃材质更接近白色塑料。
4. 卡片四周使用接近一致的白色边缘和高光，缺少“左上亮、右下暗”的边缘梯度。
5. 最近更新列表与主卡片的材料和阴影层级过于接近，空间层级没有形成清晰的前、中、后关系。

## 建议

1. 不应只提高阴影透明度；先收紧主阴影半径并增加向右下方的偏移，建立方向。
2. 加强左上窄幅高光，同时增加右下方极弱的暗边和遮蔽阴影。
3. 降低主卡片白色填充的不透明度，让背景明暗轻微透入。
4. 将主卡片、内容列表和底部导航设置为三个不同的高度级别，分别使用强、中、弱投影。
5. 保留当前中性色体系，仅调整明度差和光影位置，不重新引入彩色照明。

## 可访问性风险

大面积高亮会进一步降低浅灰辅助文字的可读性。截图只能确认视觉风险，仍需通过实际对比度测量和不同显示亮度测试验证。

## 精修结果

- 已完成方向光调整：[当时精修后截图（初版归档）](../../archive/prototype-building-original-monochrome/2026-07-24-library-lighting-refined.png)
- 主卡片改为左上窄幅受光、右下收束投影，减少均匀雾状阴影。
- 内容列表采用中等高度，搜索、筛选与顶部按钮采用浅层投影。
- 卡片表面降低白色填充不透明度，并强化右下暗边，保留中性灰白配色。
- TypeScript 检查与 Vite 生产构建通过。
