# 第三批视觉重构计划

**日期：** 2026-07-26

**状态：** 待实施

**基线：** 以 `#glass-lab` 材质实验页当前确认版本作为材质与环境光基线；正式页面的信息栏结构以本计划为准。

## 目标

- 将实验页确认的色调、折射玻璃质感和固定环境光迁移到正式移动端页面。
- 建立稳定的三层 App 结构：固定界面控制层、独立滚动组件层、固定背景层。
- 以桃花作为 `loci` 的主要视觉锚点，同时避免在普通功能图标中重复使用。
- 在不改变信息架构、业务流程和页面文案的前提下，统一组件质感与整体色调。

## 设计基线

1. 产品名称统一为 `loci`。
2. 默认环境采用烟灰色调，玻璃材质采用折射预设。
3. 背景以中性冷银灰为主体，右侧使用不规则桃色漫射光，下方使用轻微冷紫反射。
4. 环境光固定在单个移动端视口内，不跟随页面长度变化。
5. 不使用鼠标追光、鼠标视差或依赖桌面指针的交互。
6. 桃花只用于品牌、Agent 身份和少量关键视觉锚点。
7. 普通功能使用语义明确的单色线性图标，避免反复复用少数图标。
8. 顶部品牌与用户状态属于固定界面控制层；页面标题属于滚动组件层。

## 重构范围

### 1. App 外壳

- 将正式页面容器统一为 `100dvh` 的移动端 App 视口。
- 固定背景层，以及由顶部身份栏和底部导航组成的界面控制层。
- 将页面内容放入独立的原生纵向滚动容器。
- 将页面标题作为滚动容器中的首个内容组件，与正文和页面组件保持同层。
- 统一安全区、底部导航避让和滚动末端留白。

### 2. 背景与环境光

- 抽取固定银灰背景、桃色漫射光、冷紫反射和烟灰阴影令牌。
- 背景只按视口设计，不再使用与文档高度绑定的渐变位置。
- 保持反差色局部、低饱和、边缘柔和，避免整页粉紫化。
- 为玻璃折射提供稳定的明暗信息，不增加装饰性图案。

### 3. 玻璃与组件

- 将已确认的折射参数整理为共享材质预设。
- 移除正式移动端玻璃组件的鼠标跟随高光。
- 玻璃用于导航、短时控制和浮层；正文与主要阅读内容保持稳定实体表面。
- 统一边缘高光、透明度、模糊、折射、投影和圆角层级。

### 4. 顶部身份栏、页面标题、底部导航与 Agent

- 正式页面顶部身份栏左侧只显示 `loci` 桃花标志，右侧显示用户头像或用户状态。
- 顶部身份栏与底部导航同属固定界面控制层，始终存在，不随页面内容滚动或淡出。
- 顶部身份栏保持开放布局，不使用包裹整栏的胶囊或玻璃容器。
- 当前页面名称作为独立页面标题放入滚动组件层，不与 Logo 绑定。
- 页面标题随内容一起上滑并离开视口，不在顶部固定保留。
- 保持底部导航固定，并统一选中态、未选中态和安全区行为。
- 保留最右侧桃色 Agent 按钮，使用轻微冷紫反射形成层次。
- 确保导航不遮挡最后一组内容，触控目标不小于 44px。

### 5. 图标体系

- 继续使用项目内置单色 SVG 图标组件，不引入第三方图标包。
- 按资料、学习、关系、引用、收藏、导入、筛选和状态补齐语义图标。
- 校准图标的 24px 视图框、线宽、视觉尺寸和圆角语言。
- 桃花图标不承担普通功能含义。

### 6. 页面迁移顺序

1. 今日页与底部导航。
2. 知识库与资料入口。
3. 文件理解和核心学习流程。
4. 学习完成、学习成果与地图变化。
5. 学习地图和 Agent 浮层。

每完成一组页面后单独检查，不一次性覆盖全部页面。

## 非目标

- 不新增生成式文案、宣传性概念或额外功能。
- 不重写现有信息架构、用户流程和业务状态。
- 不把玻璃扩展为所有正文内容的装饰背景。
- 不增加与移动端无关的鼠标交互。
- 不在第三批重构中重新设计桃花标志。

## 验收标准

- 背景、顶部身份栏与底部导航在内容滚动时保持固定，只有中间组件层响应手势。
- 顶部身份栏左侧 Logo、右侧用户状态的结构在正式页面中保持一致，并始终可见。
- 页面标题与页面组件处于同一滚动层，下滑后自然离开视口，返回顶部后重新出现。
- 页面根节点不产生纵向滚动，内容末端不被导航遮挡。
- 所有正式页面共享一致的银灰、桃色和冷紫环境关系。
- 玻璃折射清晰但不浑浊，不出现明显圆形光斑或整页色雾。
- 桃花视觉锚点与普通功能图标职责清晰。
- 关键触控目标、文字对比、安全区和减少动态效果符合移动端要求。
- 所有迁移页面可以正常进入，TypeScript 与 Vite 生产构建通过。

## 记录要求

- 实施结果、页面清单、偏差说明、验证截图和构建结果统一写入同级 `results/`。
- 在第三批重构开始实施前，不填写结果文档。
