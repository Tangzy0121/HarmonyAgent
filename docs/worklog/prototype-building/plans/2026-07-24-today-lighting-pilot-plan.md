# 今日页方向光试点计划

**日期：** 2026-07-24

**范围：** 今日首页，不包含学习成果页。

## 目标

- 将知识库已确认的中性方向光系统迁移到今日首页。
- 降低大面积纯黑表面的视觉重量，黑色只保留给焦点核心和主操作。
- 建立主任务、进度卡和悬浮控制三个清晰高度。
- 保持现有信息结构、文案、交互路径和动效语义不变。

## 实施项

1. 为今日页增加左上主光、右下环境阴影和中性灰背景。
2. 将主任务卡改为受光的高位实体表面。
3. 将轨道核心、节点和主按钮调整为小面积近黑焦点。
4. 将下方进度视觉卡改为中等高度的中性表面。
5. 复用试点导航材质，并确保学习成果页不继承本次试点。

## 验收

- 今日页能够清晰识别左上光源和右下投影。
- 大面积黑色填充被移除，视觉焦点仍然明确。
- 主任务卡高于进度卡，进度卡高于页面背景。
- 学习成果页视觉不受影响。
- TypeScript 与 Vite 生产构建通过。
