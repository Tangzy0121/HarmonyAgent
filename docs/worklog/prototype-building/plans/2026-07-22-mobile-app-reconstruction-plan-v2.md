# 移动端 App 重构说明 V2

**日期：** 2026-07-22
**状态：** 视觉基线已完成，继续作为后续页面设计依据
**实现范围：** `admin/` 中的四张移动端视觉基准页与必要组件
**数据边界：** 继续使用本地模拟数据，不接入后端，不扩展产品需求

本文档取代 `docs/worklog/archive/` 中的三份历史计划；归档文档仅用于追溯，不再作为设计或实施依据。下一批页面的实施任务见《2026-07-22-p1-core-learning-loop-plan.md》。

## 1. 重构结论

当前版本虽然已经具备移动端页面结构和主要交互，但视觉仍停留在“自定义网页组件适配到手机尺寸”的阶段。主要问题包括：暖中性色画布显得厚重；卡片边界过多；字符图标不统一；液态玻璃缺少明确的内容层与控制层关系；页面之间的构图差异和品牌气质不足。

V2 不继续围绕现有样式做局部修补，而是保留可用的状态、数据和手势逻辑，重新建立视觉 Token、应用壳、图标、导航、页面构图与玻璃材质。

## 2. 已确定的设计方向

1. 产品形态是移动端知识管理 App，不是官网、落地页、管理后台或概念展示页。
2. 视觉参照采用 **Apple Music 的沉浸式内容关系**、**App Store 的编辑式信息组织**和 **Apple Liquid Glass 的浮动控制层原则**。
3. 核心配色只使用纯黑与纯白；其他颜色只能表达状态、类别或 Agent 身份。
4. Liquid Glass 只用于导航、工具、筛选、浮层和瞬时交互反馈，不用于正文、普通列表行、知识节点或大面积页面背景。
5. 第一阶段仍只实现今日、学习地图、知识库和默认 75% Agent 抽屉四个基准状态。
6. 不复制 Apple 的品牌资产或页面内容，只借鉴层级、节奏、材质边界和移动端交互规律。

参考：

- [Apple — Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)
- [Apple — Get to know the new design system](https://developer.apple.com/videos/play/wwdc2025/356/)

## 3. 黑白视觉系统

### 3.1 核心颜色

| 语义 | 建议值 | 用途 |
| --- | --- | --- |
| `canvas` | `#FFFFFF` | 页面和连续内容画布 |
| `ink` | `#000000` | 主文字、主按钮、选中态和高权重图标 |
| `on-ink` | `#FFFFFF` | 黑色表面上的文字和图标 |
| `secondary-ink` | `rgba(0, 0, 0, 0.56)` | 次级说明与元数据 |
| `tertiary-ink` | `rgba(0, 0, 0, 0.34)` | 弱提示、占位和非活动状态 |
| `separator` | `rgba(0, 0, 0, 0.10)` | 列表分隔线和弱边界 |
| `pressed` | `rgba(0, 0, 0, 0.06)` | 浅色表面的按压反馈 |
| `scrim` | `rgba(0, 0, 0, 0.22)` | 抽屉与背景之间的空间分离 |

不再使用暖米白、暖灰褐色或蓝色作为品牌底色和主操作色。灰阶全部由黑色透明度生成，避免出现多套近似中性色。

### 3.2 辅助色

辅助色必须低面积使用，并同时配合文字、形状或图标，不能单独依靠颜色表达状态：

- 绿色：已掌握、处理完成；
- 橙色：待复习、需要关注；
- 红色：错误、失败或危险操作；
- 紫色：Agent、智能生成或推断关系；
- 青色：引用、连接或来源关系。

辅助色不得用于大面积页面背景、主导航选中态或普通按钮。

## 4. 材质与空间层级

### 4.1 内容层

- 纯白、连续、少边框；
- 通过排版、留白、对齐和内容图形建立层级；
- 普通资料行、正文、任务内容和地图节点保持实体表面；
- 删除目前大面积暖灰卡片和同质化圆角容器。

### 4.2 控制层

- 底部导航、Agent 入口、地图工具和少量筛选使用透明白玻璃；
- 玻璃必须能看到下方内容，但文字和图标始终保持足够对比；
- 静止时材质克制，按压、选中、合并和展开时才增强高光、折射感和形变；
- 不支持模糊或用户启用减少透明度时，回退为高不透明白色表面。

### 4.3 浮层

- Agent 75% 状态使用较厚玻璃，并添加克制遮罩；
- Agent 全屏状态逐渐转为纯白实体阅读面；
- 节点详情保持约 30% 的轻量信息面板，不与 Agent 使用相同体量；
- 浮层圆角与屏幕圆角保持同心关系。

## 5. 排版与图标

- Web 使用系统字体栈，优先匹配 SF Pro 的字重、字面和数字节奏，不引入装饰性衬线字体。
- ArkUI 迁移时映射为系统默认中文字体，不依赖 Web 字体文件。
- 页面标题、内容标题、正文、元数据和标签建立稳定的五级类型角色，不以随意字号制造差异。
- 所有结构性图标改用统一的单色 SVG 线性图标；禁止继续使用 `⌕`、`＋`、`•••` 等字符充当正式图标。
- 图标视觉尺寸保持统一，实际触控区域不小于 44 × 44px。

## 6. 四张页面的新构图

### 6.1 今日

参考 Apple Music 的内容聚焦方式，但不制作宣传式封面：

- 顶部只保留日期和简洁问候；
- 当前任务成为内容主角，以排版、局部黑色图形或资料缩略图建立识别，不使用厚重灰色大卡；
- 页面只保留一个纯黑主操作；
- 近期变化采用水平内容轨道，但卡片边界更弱、内容关系更强；
- 内容可自然延伸到底部玻璃导航下方。

### 6.2 学习地图

- 地图画布从顶部信息区下方连续延伸到底部；
- 黑白节点结构作为主体，辅助色只标记类别和学习状态；
- 顶栏、筛选、缩放和图例作为独立玻璃控制组悬浮于地图上；
- 节点选择、缩放、惯性、弱吸附和详情面板继续复用现有逻辑；
- 删除包裹地图的普通内容卡和长期占位工具区。

### 6.3 知识库

参考 App Store 的编辑式分区和高质量列表节奏：

- 顶部使用清晰标题、当前范围和搜索入口；
- 资料用统一比例的黑白几何封面、文件类型和标题建立识别；
- 列表以分隔线和排版对齐为主，不为每一行添加独立卡片；
- 处理状态、来源和更新时间形成稳定的元数据列；
- 导入入口保持次级，不能成为页面视觉中心。

### 6.4 Agent

- 独立圆形入口继续位于底部导航右侧；
- 入口与导航共享材质语言，但保持独立操作语义；
- 默认打开到 75%，保留背景页面可见性与上下文关系；
- 保留关闭、75%、全屏三种状态以及拖动阻力、速度判断和吸附；
- 上下文标签、建议问题和输入区采用黑白排版，紫色只作为极小面积的 Agent 状态标识；
- 全屏后降低透明度并转为纯白阅读面。

## 8. 动效原则

- 动效只表达触摸反馈、层级变化、导航切换、抽屉拖动和地图空间关系；
- 普通控件反馈保持在 150–300ms，复杂抽屉吸附不超过 400ms；
- 优先使用 `transform` 和 `opacity`，避免通过宽高动画触发布局抖动；
- 导航选中态可在同一玻璃控制组内平滑移动和融合；
- 抽屉与地图动画必须可中断，手指重新接触后立即接管；
- `prefers-reduced-motion` 下取消非必要插值和形变，只保留直接状态切换。

## 9. 实施顺序

1. **V2-01：视觉基础**——替换颜色、排版、圆角、阴影、层级和图标 Token，删除暖色遗留。
2. **V2-02：应用壳与导航**——重做 `AppShell`、底部导航、Agent 入口和玻璃控制组，先解决所有页面共同基线。
3. **V2-03：今日页**——重做任务聚焦区和近期变化轨道。
4. **V2-04：学习地图**——重做节点视觉、悬浮工具和详情面板，不修改现有地图数据和核心手势能力。
5. **V2-05：知识库**——重做编辑式资料分区、封面与元数据列表。
6. **V2-06：Agent**——重做 75% / 全屏材质、遮罩、输入区与上下文表达，保留现有吸附状态机。
7. **V2-07：验收**——在 375、390 和 430px 宽度检查四张基准页、软键盘、安全区、减少动态效果和减少透明度，并重新采集截图。

每一步完成后先截图对照，再进入下一步，避免在错误视觉方向上连续叠加实现。

## 10. 验收标准

- 页面第一眼必须是移动端 App，而不是响应式网页或宣传落地页。
- 去除玻璃效果后，内容层级和操作优先级仍然成立。
- 黑白承担品牌与主要操作，辅助色只表达状态且面积受控。
- 普通内容不依赖阴影和圆角卡片形成分组。
- 底部导航与 Agent 入口在 375px 宽度下完整可见，触控区域不小于 44 × 44px。
- 今日、地图、知识库和 Agent 具有不同的信息构图，但共享同一套排版、图标、材质和运动规则。
- 地图与 Agent 的物理交互保持可中断、有阻力、有吸附，并提供可见的非手势操作。
- Web 版本不绑定第三方 UI 框架，组件状态和数据结构可以逐项映射到 ArkUI。

## 11. ArkUI 迁移说明

- 黑白颜色、透明度、排版角色、间距、圆角和层级定义为平台无关 Token；
- Web 的 `GlassSurface` 在 ArkUI 中映射为原生材质与模糊能力，不复制 CSS 滤镜参数；
- SVG 图标在 ArkUI 侧替换为同语义的矢量资源，保持尺寸和状态一致；
- 抽屉只迁移关闭、75%、全屏、位移、速度和吸附结果，不迁移 DOM Pointer Event 实现；
- 地图只迁移视口、焦点、节点状态和平移缩放语义，不迁移 Web 事件对象；
- 本阶段继续以 Web 原型验证视觉和交互，暂不修改 `entry/`。
