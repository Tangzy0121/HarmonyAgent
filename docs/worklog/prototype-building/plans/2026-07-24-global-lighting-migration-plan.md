# 全页面方向光迁移计划

**日期：** 2026-07-24

**范围：** 所有正式原型页面，不包含材质实验页。

## 目标

- 将知识库与今日首页确认的中性方向光提升为应用级环境。
- 统一背景、内容实体、浮层控制和黑色焦点的空间关系。
- 移除正式页面中作为大面积内容背景使用的纯黑表面。
- 保持现有信息结构、文案、路由、交互和动效语义不变。

## 页面范围

1. 今日首页。
2. 今日学习成果。
3. 知识库。
4. 文件理解。
5. 学习解释。
6. 学习验证。
7. 学习完成。
8. 学习地图。
9. 地图变化聚焦。

## 实施项

1. 将方向光材质类应用到整个 AppShell。
2. 建立统一页面背景、内容表面、边缘高光与投影令牌。
3. 统一顶部导航、状态控件、底部主操作和地图浮层的玻璃材质。
4. 将今日成果、Agent 阅读结果、学习证据和地图证据迁移为中性受光实体。
5. 保留黑色用于主按钮、选中态、知识节点、轨道核心和资料封面。
6. 逐页检查文本对比、遮挡、滚动和页面状态隔离。

## 验收

- 正式页面使用同一左上主光和右下投影。
- 不再存在作为大面积内容底色的纯黑卡片。
- 阅读与验证页面保持稳定、清晰的实体画布。
- 地图节点、底部浮层和悬浮控制具有一致高度关系。
- 所有路由可以正常进入，TypeScript 与 Vite 生产构建通过。
