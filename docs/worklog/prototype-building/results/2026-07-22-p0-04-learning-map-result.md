# P0-04 学习地图基准页验收记录

**日期：** 2026-07-22
**状态：** 已完成，后于同日按 `rectification.md` 重构为画布优先的移动端地图。
**实现位置：** `admin/src/pages/LearningMapPage.tsx`、`admin/src/hooks/useMapGesture.ts`、`admin/src/data/learningMap.ts`

## 已实现内容

- 以《机器学习》第三章的模拟节点和关系渲染连续、可探索的知识地图，而非静态思维导图。
- 用低饱和类别色区分方法、理论、实践与应用；学习中、待复习和已掌握只通过独立标记表达，不与类别色混淆。
- 支持单指/指针平移、双指缩放、滚轮缩放、边缘阻力、受限视口和短促惯性；缩放会在接近预设层级时弱吸附。
- 纠偏后删除介绍式大标题、模拟数据提示与长期图例；紧凑工具栏、范围信息和筛选器位于顶部，地图成为页面主体。
- 点击节点会将目标聚焦至地图上部区域，并浮现约 30% 高度的节点信息面板；75% / 全屏抽屉仅保留给 Agent。
- 提供缩小、复位、放大三个非手势控制，满足可访问性与可发现性要求。

## 验收与验证

- 在 390 × 844 移动视窗检查默认构图，底部导航保持固定，地图内容、筛选和紧凑控制层均可辨认。
- 实测“监督学习”节点聚焦后，约 30% 高度的信息面板显示概要、关联数量与继续学习出口。
- 实测拖拽后的惯性受限；修正快速指针事件下的速度上限后，不再出现过度甩出视区的现象。
- 已执行 TypeScript 静态检查：通过。
- 已执行 Vite 生产构建：通过（40 个模块转换完成）。
