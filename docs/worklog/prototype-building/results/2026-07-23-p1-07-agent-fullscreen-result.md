# P1-07 Agent 全屏态验收结果

**日期：** 2026-07-23

**状态：** 已完成

**实现范围：** `admin/` 移动端高保真前端原型，使用本地模拟数据

## 1. 交付结论

已补全自由 Agent 的关闭、75% 厚玻璃抽屉与全屏纯白实体三个稳定状态。全屏态不再只是放大的首屏提示，而是具备适合长对话阅读的消息、引用、继续追问、历史记录、新建对话和固定输入区。

Agent 继续继承打开前页面的弱上下文，关闭或从全屏返回后不改变原页面路由、地图视口和会话草稿。模拟消息仍只围绕《机器学习》第三章与“监督学习”知识点，没有扩展新的产品主题或接入后端。

## 2. 已实现内容

1. 保留 75% 厚 Liquid Glass 抽屉；
2. 增加全屏纯白实体阅读表面；
3. 增加历史记录入口和三条模拟历史记录；
4. 增加新建对话入口与空白建议问题状态；
5. 增加编辑式消息列表，不使用彩色气泡堆叠；
6. 增加用户消息、Agent 回答、两步判断依据和继续追问；
7. 增加可追溯引用，显示资料名称、页码与引用摘要；
8. 当前页面作为可移除的弱上下文显示；
9. 固定输入区独立于可滚动阅读表面，并避让底部安全区；
10. 输入框聚焦时，75% 抽屉自动吸附到全屏；
11. 输入结束后恢复聚焦前的 75% 高度；
12. 提交模拟问题后追加用户消息、Agent 回答与引用，并滚动到最新内容；
13. 增加“全屏 / 返回 75%”可见按钮，拖拽把手不再是唯一入口；
14. 浏览器或系统返回遵循“全屏 → 75% → 关闭”的层级；
15. `Escape` 遵循同一返回层级；
16. 抽屉打开时锁定后方页面滚动，关闭后恢复；
17. 页面标题在全屏态切换为“Knowledge Agent · 对话”；
18. 截图脚本增加 `agent-full` 目标；
19. 模拟数据、图标和会话状态保持前端本地实现。

## 3. 材质与空间验收

- 75% 状态保持中性白厚玻璃、背景模糊、顶部大圆角和宽阴影；
- 上拉过程中抽屉优先增长高度，不以整块向上平移制造假全屏；
- 玻璃透明度、背景模糊和顶部圆角随全屏进度连续收束；
- 全屏落点为纯白实体、无模糊、无顶部圆角；
- 从全屏向下拖动时恢复玻璃进度与后方页面关系；
- 释放吸附仍结合距离与速度，保留原有边界阻力；
- 系统减少动态效果时，动画与过渡缩短为近乎即时；
- 紫色只用于 Agent 图标和弱上下文状态点。

## 4. 视觉验收

- 基准视口：`390 × 844`；
- 小屏视口：`360 × 800`；
- 两档视口均无横向内容溢出；
- 全屏抽屉顶部为 `0`，高度与视口一致；
- 固定输入区底部始终位于安全区上方；
- 对话正文使用单列、分隔线和留白组织，不使用聊天气泡瀑布；
- 引用使用浅灰实体表面，正文保持纯白；
- 历史记录使用编辑式行列表，不使用卡片矩阵；
- 触控按钮和输入区均满足至少 `44px` 的目标尺寸。
