## 1. 交付结论

已完成学习完成页到地图变化聚焦的真实链路。用户点击“查看地图变化”后进入同一张学习地图，镜头聚焦“监督学习”节点，本次新增的“训练数据 → 监督学习”关系使用短期青色标记，节点通过绿色小标记与“已掌握”文字共同表达学习状态。

底部新增独立的纯白节点变化面板，稳定覆盖约 30% 视口，集中展示新增学习证据、来源文件和关系。主操作“安排下一次”只进入准备状态，P1-06 的成果确认与日期安排不在本任务提前实现。

## 2. 已实现内容

1. 新增 `#learning/supervised-learning/change` 深链与浏览器历史状态；
2. P1-04 主操作真实进入 P1-05，不再停留在本地准备状态；
3. 进入时临时隐藏底部一级导航与 Agent 入口，保持地图任务聚焦；
4. 复用现有学习地图、节点数据、拖拽、惯性、阻力与缩放吸附；
5. 自动把“监督学习”吸附到节点面板上方的焦点区；
6. 聚焦镜头同时保留“训练数据”、核心节点与新关系的局部结构；
7. 本次关系使用青色虚线短期标记，不改变长期知识类别语义；

13. 关闭面板恢复进入节点聚焦前的地图视口；
14. 普通地图节点面板关闭与点击空白也同步恢复聚焦前视口；
15. “安排下一次”提供明确准备反馈，但不实现 P1-06；

## 3. 视觉与动效验收

- 基准视口 `390 × 844` 已完成真实页面视觉检查；
- 地图保持纯白连续画布和黑白节点，青色与绿色只占极小语义面积；
- 目标节点、一阶关系和学习证据形成单一视觉焦点；
- 面板高度约为视口的 `31%`，后方保留大部分地图；
- 学习证据使用黑色实体记录，来源与关系保持可追溯；
- 镜头使用短距离平移与语义缩放吸附，不进行自动漫游；
- 节点脉冲只播放一次，关系线只执行一次落位动效；
- `prefers-reduced-motion` 下所有大范围移动、脉冲和面板进入动效缩短至近乎即时；
- 最后一轮移除了会遮挡目标节点的地图缩放工具，任务结束后普通地图工具仍保留。
