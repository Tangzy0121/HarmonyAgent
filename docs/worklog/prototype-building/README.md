# Prototype Building Worklog

本目录记录移动端高保真原型的实施计划与验收结果。

## 目录

- `plans/`：阶段计划、范围和验收口径。
- `results/`：阶段结果文档与必要的视觉证据。

## 视觉证据保留规则

- 每个结果默认只保留一张最终代表图。
- 只有初始态与反馈态、收起态与展开态等关键交互差异，才保留第二张。
- 不保留同一页面的小屏重复截图、临时裁切、迭代中间稿或可由脚本重新生成的比较图。
- 视频和封面不在 worklog 重复归档；最终可交付文件统一存放在 `video/out/final/`。
- 删除视觉证据时，同步更新结果文档，避免失效链接。
